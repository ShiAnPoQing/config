*'statusline'* *'stl'* *E540* *E542*
'statusline' 'stl'	字符串	(默认值非常长)
			全局或窗口局部 |global-local|
	设置 |status-line|（状态行）。

	该选项由穿插普通文本的 printf 风格的 '%' 项组成。每个状态行项的形式为：
	  %-0{minwid}.{maxwid}{item}
	除 {item} 外的所有字段都是可选的。单个百分号可以写作 "%%"。

							*stl-%!*
	当选项以 "%!" 开头时，它被用作一个表达式，计算后其结果用作选项值。示例： >vim
		set statusline=%!MyStatusLine()
<	*g:statusline_winid* 变量将被设置为该状态行所属窗口的 |window-ID|。
	结果可以包含也会被计算的 %{} 项。
	注意 "%!" 表达式是在当前窗口和缓冲区的上下文中计算的，而 %{} 项是在状态行所属窗口的
	上下文中计算的。

	当计算选项时出现错误，它将被重置为其默认值以避免进一步错误。否则屏幕更新会循环。
	当结果包含不可打印字符时，结果不可预测。

	注意当设置此选项（且 'laststatus' 为 2 或 3）时，'ruler' 的唯一作用是控制 |CTRL-G|
	的输出。

	字段	    含义 ~
	-	    左对齐项。默认为右对齐，当 minwid 大于项的长度时。
	0	    数字项中的前导零。被 "-" 覆盖。
	minwid	    项的最小宽度，按 "-" 和 "0" 设置进行填充。值必须为 50 或更小。
	maxwid	    项的最大宽度。对于文本项，会在左侧出现 "<" 进行截断。数字项将被缩减为
		    maxwid-2 位数字，后跟 ">"number，其中 number 是缺失的位数，
		    很像指数表示法。
	item	    一个字母代码，如下所述。

	以下是可能的状态行项的描述。"item" 中的第二个字符是类型：
		N 表示数字
		S 表示字符串
		F 表示如下所述的标志
		- 不适用

	item  含义 ~
	f S   缓冲区中文件的路径，如所输入或相对于当前目录。
	F S   缓冲区中文件的完整路径。
	t S   缓冲区中文件的文件名（尾部）。
	m F   修改标志，文本为 "[+]"；如果 'modifiable' 关闭，则为 "[-]"。
	M F   修改标志，文本为 ",+" 或 ",-"。
	r F   只读标志，文本为 "[RO]"。
	R F   只读标志，文本为 ",RO"。
	h F   帮助缓冲区标志，文本为 "[help]"。
	H F   帮助缓冲区标志，文本为 ",HLP"。
	w F   预览窗口标志，文本为 "[Preview]"。
	W F   预览窗口标志，文本为 ",PRV"。
	y F   缓冲区中文件的类型，例如 "[vim]"。参见 'filetype'。
	Y F   缓冲区中文件的类型，例如 ",VIM"。参见 'filetype'。
	q S   "[Quickfix List]"（快速修复列表）、"[Location List]"（位置列表）或空。
	k S   使用 |:lmap| 映射时 "b:keymap_name" 或 'keymap' 的值："<keymap>"
	n N   缓冲区编号。
	b N   光标下字符的值。
	B N   同上，十六进制表示。
	o N   光标下字节在文件中的字节编号，第一个字节为 1。
	      助记：从文件开始的偏移量（加 1）
	O N   同上，十六进制表示。
	l N   行号。
	L N   缓冲区中的行数。
	c N   列号（字节索引）。
	v N   虚拟列号（屏幕列）。
	V N   虚拟列号，显示为 -{num}。如果等于 'c' 则不显示。
	p N   文件中的行数百分比，如 |CTRL-G| 所示。
	P S   显示窗口在文件中的百分比。这类似于 'ruler' 描述的百分比。除非被翻译，
	      长度始终为 3。
	S S   'showcmd' 内容，参见 'showcmdloc'。
	a S   参数列表状态，如默认标题中所示。（{current} of {max}）
	      如果参数文件计数为零或一，则为空。
	{ NF  计算 "%{" 和 "}" 之间的表达式并替换结果。注意结尾的 "}" 之前没有 "%"。
	      表达式不能包含 "}" 字符，可以通过调用函数来解决。参见下面的 |stl-%{|。
	`{%` - 与 "{" 几乎相同，只是表达式的结果会作为状态行格式字符串被重新计算。
	      因此如果 expr 的返回值包含 "%" 项，它们将被展开。
	      表达式可以包含 "}" 字符，表达式的结束由 "%}" 表示。
	      例如： >vim
		func! Stl_filename() abort
		    return "%t"
		endfunc
<	        `stl=%{Stl_filename()}`   结果为 `"%t"`
	        `stl=%{%Stl_filename()%}` 结果为 `"当前文件的名称"`
	%} -   "{%" 表达式的结束
	( -    项目组的开始。可用于设置某个部分的宽度和对齐方式。后面必须有 %)。
	) -    项目组的结束。不允许宽度字段。
	T N    对于 'tabline'：标签页 N 标签的开始。使用 %T 或 %X 结束标签。
	      用鼠标左键单击此标签切换到指定的标签页，而用鼠标中键单击关闭指定的标签页。
	X N    对于 'tabline'：关闭标签 N 标签的开始。使用 %X 或 %T 结束标签，
	      例如：%3Xclose%X。使用 %999X 作为“关闭当前标签”标签。
	      用鼠标左键单击此标签关闭指定的标签页。
	@ N    执行函数标签的开始。使用 %X 或 %T 结束标签，
	      例如：%10@SwitchBuffer@foo.c%X。单击此标签运行指定的函数：
	      在示例中，当用鼠标左键单击 "foo.c" 一次时，将运行一个
	      `SwitchBuffer(10, 1, 'l', '    ')` 表达式。指定的函数按顺序接收以下参数：
	      1. minwid 字段值，如果未指定 N 则为零
	      2. 鼠标点击次数，用于检测多次点击
	      3. 使用的鼠标按钮：分别代表左、右或中键的 "l"、"r" 或 "m"；
	         不应依赖第三个参数只能是 "l"、"r" 或 "m"：对于其他鼠标按钮，
	         可能期望任何其他仅包含 ASCII 小写字母的非空字符串值。
	      4. 按下的修饰键：一个字符串，如果按下了 shift 修饰键则包含 "s"，
	         如果按下了 control 则包含 "c"，如果按下了 alt 则包含 "a"，
	         如果按下了 meta 则包含 "m"；目前如果修饰键未被按下，字符串包含空格，
	         但不应依赖空格的存在或修饰键的特定顺序：使用 |stridx()| 来测试某个
	         修饰键是否存在；保证字符串仅包含 ASCII 字母和空格，每个修饰键一个字母；
	         "?" 修饰符也可能存在，但它的存在是一个 bug，表示添加了新的鼠标按钮识别，
	         但没有修改响应此标签上鼠标点击的代码。
	     在指定函数中使用 |getmousepos()|.winid 来获取点击项对应的窗口 ID。
	< -    如果行太长，在此处截断。默认在开头。不允许宽度字段。
	= -    对齐部分之间的分隔点。每个部分将被等数量的空格分隔。使用一个 %=，
	      其后的内容将右对齐。使用两个 %=，则有一个中间部分，其左右有空白。
	      不允许宽度字段。
	# -    设置高亮组。名称必须跟在后面，然后再跟一个 #。因此使用 %#HLname# 表示
	      高亮组 HLname。使用相同的高亮，也用于非当前窗口的状态行。
	$ -    与 `#` 相同，只是 `%$HLname$` 组将继承前面的高亮属性。
	* -    将高亮组设置为 User{N}，其中 {N} 取自 minwid 字段，例如 %1*。
	      使用 %* 或 %0* 恢复普通高亮。User{N} 和 StatusLine 之间的差异将应用于
	      非当前窗口状态行的 StatusLineNC。
	      数字 N 必须在 1 到 9 之间。参见 |hl-User1..9|

	显示标志时，如果该标志紧跟在纯文本之后，Vim 会移除开头的逗号（如果有）。
	当标志像下面的示例中那样使用时，这将产生良好的显示效果。

	当组中的所有项都变为空字符串（即未设置的标志）且未为组设置 minwid 时，整个组将变为空。
	这将使得当没有任何标志被设置时，像下面这样的组从状态行中完全消失。 >vim
		set statusline=...%(\ [%M%R%H]%)...
<	注意，每次显示状态行时都会计算表达式。
				*stl-%{* *g:actual_curbuf* *g:actual_curwin*
	在计算 %{} 时，当前缓冲区和当前窗口将临时设置为当前正在绘制其状态行的窗口（和缓冲区）。
	表达式将在该上下文中计算。变量 "g:actual_curbuf" 被设置为真实当前缓冲区的 `bufnr()`
	编号，"g:actual_curwin" 被设置为真实当前窗口的 |window-ID|。这些值是字符串。

	如果 'statusline' 选项是从模型线设置的，它将在 |sandbox| 中计算，参见 |sandbox-option|。
	当 'modelineexpr' 关闭时，此选项不能在模型线中设置。

	在计算 'statusline' |textlock| 时，不允许更改文本或跳转到另一个窗口。

	如果状态行未在您期望的时候更新（例如，在设置了一个用于表达式中的变量之后），
	您可以使用 `:redrawstatus` 强制更新。

	全部由数字组成的结果在显示时被视为一个数字。否则，结果被视为标志文本，并应用上述规则。

	注意表达式中的错误。它们可能会使 Vim 无法使用！
	如果您卡住了，按住 ':' 或 'Q' 获取提示，然后退出并使用 "vim --clean" 编辑您的 vimrc
	或其他文件以使其正确。

	示例：
	模拟设置了 'ruler' 的标准状态行 >vim
	  set statusline=%<%f\ %h%w%m%r%=%-14.(%l,%c%V%)\ %P
<	类似，但添加光标下字符的 ASCII 值（如 "ga"） >vim
	  set statusline=%<%f%h%m%r%=%b\ 0x%B\ \ %l,%c%V\ %P
<	显示字节计数和字节值，修改标志用红色显示。 >vim
	  set statusline=%<%f%=\ [%1*%M%*%n%R%H]\ %-19(%3l,%02c%03V%)%O'%02b'
	  hi User1 term=inverse,bold cterm=inverse,bold ctermfg=red
<	如果加载了压缩文件，显示一个 ,GZ 标志 >vim
	  set statusline=...%r%{VarExists('b:gzflag','\ [GZ]')}%h...
<	在 |:autocmd| 中： >vim
	  let b:gzflag = 1
<	以及： >vim
	  unlet b:gzflag
<	并定义此函数： >vim
	  function VarExists(var, val)
	      if exists(a:var) | return a:val | else | return '' | endif
	  endfunction
<
