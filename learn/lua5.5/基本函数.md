# 基本函数

## `assert(v, [, message])`

> 断言真假

如果参数 `v` 的值为假(`false` or `nil`)，则引发错误；否则返回所有参数。

如果发生错误， `message` 是错误对象；如果忽略，则默认为 `assertion failed!`

## `collectgarbage([opt [, arg]])`

此函数是垃圾回收器的通用接口。它根据其第一个参数 opt 执行不同的功能

"collect"：执行一个完整的垃圾回收周期。这是默认选项。
"stop"：停止垃圾回收器的自动执行。回收器只会在显式调用时运行，直到调用重新启动它。
"restart"：重新启动垃圾回收器的自动执行。
"count"：返回 Lua 使用的总内存（以 Kbytes 为单位）。该值有小数部分，乘以 1024 即可得到 Lua 使用的精确字节数。
"step"：执行一个垃圾回收步骤。此选项后面可以跟一个额外的参数，一个整数，表示步长。
如果大小为正整数 n，则回收器会像分配了 n 个新字节一样操作。如果大小为零，则回收器执行基本步骤。在增量模式下，基本步骤对应于当前步长。在分代模式下，如果回收器已安排，则基本步骤执行一次完整的次级回收或增量步骤。

在增量模式下，如果步骤完成了一个回收周期，则函数返回 true。在分代模式下，如果步骤完成了一次主要回收，则函数返回 true。

"isrunning"：返回一个布尔值，指示回收器是否正在运行（即未停止）。
"incremental"：将回收器模式更改为增量模式并返回以前的模式。
"generational"：将回收器模式更改为分代模式并返回以前的模式。
"param"：更改和/或检索回收器参数的值。此选项必须后跟一个或两个额外的参数：要更改或检索的参数名称（字符串）和该参数的可选新值，一个介于 [0,100000] 范围内的整数。第一个参数必须具有以下值之一
"minormul"：次要乘数。
"majorminor"：主次乘数。
"minormajor"：次主乘数。
"pause"：垃圾回收器暂停时间。
"stepmul"：步进乘数。
"stepsize"：步进大小。
调用总是返回参数的先前值。如果调用未给出新值，则该值保持不变。

Lua 以压缩格式存储这些值，因此，作为先前值返回的值可能并非精确地是最后设置的值。

有关垃圾回收和其中一些选项的更多详细信息，请参见 §2.5。

此函数不应由终结器调用。

## `dofile([filename])`

> 打开指定文件并将其内容作为 Lua 块执行，返回该块返回的所有值。

当不带参数调用时， `dofile` 执行标准输入(stdin)的内容

如果发生错误， `dofile` 会将错误传播给其调用者

## `error(message [, level])`

>引发一个错误，其中 `message` 作为错误对象。此函数从不返回

通常，如果 `message` 是字符串， `errro` 会在消息开头添加一些关于错误位置的信息。

`level` 参数指定如何获取错误位置。

- `1` (默认)：错误位置是调用 `error` 函数的地方
- `2`：错误指向调用 `error` 的函数的调用位置；依次类推
- `0`：会避免向消息中添加错误位置信息

## `_G`

一个全局变量（不是函数），它持有全局环境

Lua 本身不使用此变量；改变其值不会影响任何环境，反之亦然



## `ipairs(t)`

返回三个值(迭代器函数，值`t`， 和 `0`)，以便构造

~~~lua
for i,v in ipairs(t) do body end
~~~

将迭代键值对`(1, t[1])`，`(2, t[2])`,...,直到第一个不存在的索引

## `load(chunk [, chunkname [, mode [, env]]])`

> 加载一个代码块

如果 `chunk` 是字符串，则该块就是该字符串

如果 `chunk` 是函数，`load` 会重复调用它以获取块的片段。
每次调用`chunk` 都必须返回一个与之前结果连接的字符串。
返回字符串、`nil` 或无值表示块的结束。

如果没有语法错误，`load` 将编译后的块作为函数返回；

否则，它返回 fail 以及错误消息。

如果没有语法错误，load 将编译后的块作为函数返回；否则，它返回 fail 以及错误消息。

当您加载一个主代码块时，生成的函数将始终只有一个上值，即 _ENV 变量（参见 §2.2）。然而，当您加载从函数创建的二进制代码块（参见 string.dump）时，生成的函数可以有任意数量的上值，并且不能保证其第一个上值是 _ENV 变量。（非主函数甚至可能没有 _ENV 上值。）

无论如何，如果结果函数有任何 upvalue，其第一个 upvalue 将设置为 env 的值（如果给定该参数），或设置为全局环境的值。其他 upvalue 用 nil 初始化。所有 upvalue 都是新的，也就是说，它们不与任何其他函数共享。

chunkname 用作错误消息和调试信息（参见 §4.7）的块名称。如果省略，如果 chunk 是字符串，则默认为 chunk，否则默认为“=(load)”。

字符串 mode 控制块可以是文本还是二进制（即预编译块）。它可以是字符串“b”（仅二进制块）、“t”（仅文本块）或“bt”（二进制和文本）。默认值为“bt”。

Lua 不检查二进制块的一致性。恶意制作的二进制块可能会使解释器崩溃。您可以使用 mode 参数来防止加载二进制块。

## `pcall(f[, arg1, ...])`

`pcall` 以保护模式调用函数 f 并传入给定的参数。
这意味着 f 内部的任何错误都不会传播；
相反，`pcall` 会捕获错误并返回一个状态码。
它的第一个结果是状态码（布尔值），如果调用成功且无错误，则状态码为 true。
在这种情况下，`pcall` 还会返回除第一个结果之外的所有调用结果。
如果发生任何错误，`pcall` 将返回 false 以及错误对象。
请注意，`pcall` 捕获的错误不会调用消息处理程序。

保护模式：函数出错不会程序崩溃
错误不传播：错误被 `pcall` 拦截，不会向上传递
错误对象可以是任何类型

~~~lua
local function readFile(filename)
    local file = io.open(filename, "r")
    if not file then
        error("无法打开文件: " .. filename)
    end
    local content = file:read("*all")
    file:close()
    return content
end

-- 安全地读取文件
local success, content = pcall(readFile, "config.json")
if success then
    print("文件内容:", content)
else
    print("读取失败，使用默认配置:", content)  -- content 是错误信息
    -- 使用默认配置继续运行
end
~~~

## `print(...)`

接收任意数量的参数，并将它们的值打印到标准输出（stdout），
同时根据 `tostring` 的规则将每个参数转换为字符串。

`print` 函数并非用于格式化输出，而仅用于快速显示值，例如用于调试。
要完全控制输出，请使用 `string.format` 和 `io.write`。

1. 不用于格式化输出，而仅用于快速显示值
2. 接收任意数量的参数，并将它们的值打印到标准输出 
3. 将每个参数转换为字符串(`tostring` 规则)

## `rawequal(v1: any, v2: any): boolean`

检查 v1 是否等于 v2，而不调用 `__eq` 元方法。
返回 boolean

## `rawget(table: table, index: any): any`

获取 `table[index]` 的实际值，不使用 `__index` 元值。
table 必须是表，索引可以是任何值。

## `rawlen(v: table|string): integer` 

返回对象 v 的长度， v 必须是表格或字符串，而不调用 `__len` 元方法。
返回一个整数。

## `rawset(table: table, index, value: any): table`

将 `table[index]` 的实际值设置为 `value`，不使用 `__newindex` 元值。
`table` 必须是一个表，`index` 可以是除 `nil` 和 `NaN` 之外的任何值，
`value` 可以是任何 Lua 值。
返回 `table`

## `select(index, ...)`

如果 `index` 是一个数字，则返回从 `index`，之后的所有参数；
负数索引从末尾开始(-1表示最后一个参数)。

否则，`index` 必须为字符串 `#`，select 函数返回接收到的额外参数的总数 


~~~lua
function example(...)
    local args = {select(1, ...)}
    local a2, a3, a4 = select(2, ...)
    local total = select("#", ...)
end
~~~

## `setmetatable(table, metatable)`

设置给定 `table` 的元表。
如果 `metatable` 为 `nil`，则移除给定表的元表。
如果原始元表包含 `__metatable`，则引发错误。
此函数返回 `table`。

~~~lua
-- 伪代码
function setmetatable(obj, new_mt)
  local old_mt = obj_real_mt
  if old_mt and old_mt.__metatable ~= nil then
    error("cannot change a protected metatable")
  else
    obj_real_mt = new_mt
    return obj
  end
end
~~~

`__metatable` 是一个特殊的元表字段，用来控制元表的访问权限。

~~~lua
local t = {}
local mt = {
  __index = function(t, k)
    return "默认值"
  end,
  __metatable = "禁止访问元表"
}
setmetatable(t, mt)

-- 尝试获取元表
local result = getmetatable(t)
print(result) -- 禁止访问元表

-- 尝试修改元表
local success, err = pcall(setmetatable, t, {})
print(success) -- false
print(err) -- cannot change a protected metatable 
~~~

## `getmetatable(object)`

- 如果 `object` 没有元表，则返回 `nil`。
- 否则，如果对象的元表有一个 `__metatable` 字段，则返回关联的值。
- 否则，返回给定对象的元表

## `pairs(t)`

如果 t 有一个元方法 `__pairs`，则调用该方法并将 t 作为参数，
返回调用结果的前 4 个。

否则，返回 `next` 函数、表 t 以及两个 nil 值，以便构造函数

~~~lua
for k, v in pairs(t) do body end
~~~

## `tonumber(e[, base])`

当不带进制参数调用 `tonumber` 时，它会尝试将参数转换为数字。
如果参数已经是数字或可转换为数字的字符串，则 `tonumber` 返回该数字；否则，返回 `fail`

~~~lua
print(tonumber(12.1)) -- 12.1
print(tonumber('12.1')) -- 12.1
print(tonumber('0x11')) -- 17
print(tonumber('314.16e-2')) -- 17
print(tonumber('0x11           ')) -- 17
print(tonumber('           0x11')) -- 17

print(tonumber({})) -- nil
print(tonumber(true)) -- nil
~~~
字符串的转化结果可以是整数或浮点数。
字符串可以包含前导空格、尾随空格和符号

当带进制参数调用 `tonumber` 时， `e` 必须是一个字符串，
且该字符串将被解释为该进制下的整数。
进制可以是 2 ~ 36 之间的任意整数 (包含 2 和 36)。
在 10 以上的进制中，字母 'A'(无论大小写) 代表 10,
'B' 代表 11，依次类推，'Z' 代表 35。
如果字符串 `e` 不是给定进制的有效数字，而函数返回 fail

## `tostring(v)`

接收任意类型的值，并将其转换为人类可读格式的字符串。

如果 v 的元表包含一个 `__tostring` 字段，则 `tostring` 会调用对应的值，
并将 v 作为参数，并将调用结果用作其最终结果。

否则，如果 v 的元表包含一个值为字符串的 `_name` 字段，则 `tostring` 可能会在其最终结果中使用该字符串。

## `warn(msg1, ...)`

发出警告，警告信息由所有参数(应为字符串)连接而成。

按照管理， 以 `@` 开头的单个消息是控制消息，即发送给警告系统自身的消息。

具体来说，Lua 中的标准警告函数能够识别控制消息`@off`（用于停止发出警告）和`@on`（用于（重新）发出警告）；它会忽略未知的控制消息。

~~~lua
-- 1. 关闭警告
warn("@off")  -- 之后的 warn 调用都不会显示
warn("这条警告不会显示")
warn("这条也不会")

-- 2. 重新开启警告
warn("@on")   -- 重新启用警告
warn("这条警告会显示")  -- 正常显示

-- 3. 未知控制消息会被忽略
warn("@unknown")  -- 被忽略，不影响任何功能
warn("这条警告正常显示")
~~~

## `xpcall(f, msgh[, arg1, ...])`

该函数与 `pcall` 类似，区别在于它设置了一个新的消息处理程序 msgh。

~~~lua
local handle = function(str)
	if type(str) ~= "string" then
		error("参数类型不符")
	else
		return "你好世界"
	end
end

local msg_handle = function(error)
	print("处理错误：" .. error)
	return {
		error = error,
	}
end

local _, r = xpcall(handle, msg_handle, 1)

print(r) -- { error = "参数类型不符" }
~~~

此函数会接收原始错误对象并返回一个新的错误对象。它会在错误展开堆栈之前调用，以便收集更多关于错误的信息，例如通过检查堆栈并创建堆栈回溯。此消息处理程序仍然受到 protected 调用的保护；因此，消息处理程序内部的错误会再次调用该消息处理程序。如果此循环持续过长时间，Lua 会中断循环并返回相应的消息。消息处理程序仅在发生常规运行时错误时才会调用。它不会用于内存分配错误，也不会用于运行终结器或其他消息处理程序时发生的错误。
