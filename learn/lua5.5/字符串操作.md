# 字符串操作

该库提供用于字符串操作的通用函数，
例如查找和提取子字符串以及模式匹配。
在 Lua 中对字符串进行索引时，第一个字符位于位置 1（而不是像 C 语言那样位于位置 0）。
索引允许为负数，并且从字符串末尾开始反向索引。
因此，最后一个字符位于位置 -1，依此类推。

字符串库的所有函数都位于 `string` 表中。
它还为字符串设置了一个元表，其中 `__index` 字段指向该字符串表。
因此，您可以以面向对象的方式使用字符串函数。
例如，`string.byte(s,i)` 可以写成 `s:byte(i)`。

字符串库假定字符编码为单字节编码。

## `string.byte(s[, i[, j]])`

返回字符 `s[i]`、`s[i+1]`、...、`s[j]` 的内部数值代码。
i 的默认值为 1；j 的默认值为 i。
这些索引的修正规则与 `string.sub` 函数相同。

数值代码不一定能跨平台通用。

## `string.char(···)`

接收零个或多个整数。
返回一个长度等于参数个数的字符串，其中每个字符的内部数值代码与其对应的参数值相同。

数值代码不一定能跨平台通用。

## `string.dump(function[, strip])`

返回一个包含给定函数二进制表示(二进制块)的字符串，以便后续加载该字符串时返回函数的副本（但带有新的上值）

如果 `strip` 为真，则为了节省空间，二进制表示肯能不会包含函数的所有调试信息。

带有上值的函数仅保存上值的数量。
重新加载时，这些上值会获得新的实例。

## `string.find(s, pattern[, init[, plain]]): integer|nil, integer|nil, string|nil;`

在字符串 `s` 中查找模式的第一个匹配项目。
如果找到匹配项，则 `find` 函数返回该匹配项在 `s` 中的开始和结束的索引，否则返回 `nil`。
第三个可选的数量参数 init 指定搜索的起始位置默认为 1 ，可以为负数。
第四个可选参数 `plain` 设置为 true 时，将关闭模式匹配功能，此时函数执行的是普通“查找子字符串”操作，模式中的任何字符都不会被视为特殊字符。

如果模式包含捕获字符，则在成功匹配的情况下，除了返回两个索引之外，还会返回捕获字符的值。

## `string.format(formatstring, ...)`

返回一个格式化后的可变数量参数，其格式遵循第一个参数(必须是字符串)中给出的描述。

格式化字符串遵循与 ISO C 函数 `sprintf` 相同的规则。

可接受的转换说明符包括 A、a、c、d、E、e、f、G、g、i、o、p、s、u、X、x、%、
以及一个非 C 说明符 q。

可接受的标志包括 '-'、'+'、'#'、'0' 和空格。如果指定了宽度和精度，则都限制为两位小数。

说明符 q 会将布尔值、nil、数字和字符串格式化为 Lua 源代码中的有效常量。布尔值和 nil 以显而易见的方式（true、false、nil）写入。浮点数以十六进制形式写入，以保留完整精度。字符串用双引号括起来，必要时使用转义序列，以确保 Lua 解释器可以安全地读取它。例如，调用 `string.format('%q', 'a string with "quotes" and \n new line')`

可能会生成以下字符串：

"a string with \"quotes\" and \

new line"

此说明符不支持修饰符（标志、宽度、精度）。

转换说明符 A、a、E、e、f、G 和 g 都接受一个数字作为参数。说明符 c、d、i、o、u、X 和 x 接受一个整数。当使用 C89 编译器编译 Lua 时，说明符 A 和 a（十六进制浮点数）不支持修饰符。

说明符 s 接受一个字符串；如果其参数不是字符串，则会按照 `tostring` 的相同规则将其转换为字符串。如果指定符带有任何修饰符，则对应的字符串参数不应包含嵌入的零。

指定符 p 用于格式化 lua_topointer 返回的指针。它为表、用户数据、线程、字符串和函数提供唯一的字符串标识符。对于其他值（数字、nil、布尔值），此指定符会生成表示指针为 NULL 的字符串。
