*current-directory.txt* 

影响任何对相对路径进行操作的操作

如 ":edit ./foo.txt"
如 ":!ls" 或 ":te ls"

==============================================================================
作用域

四种:
	global
	tab
	window
	buffer

优先级从最窄到最宽： >
	buffer  > window > tab > global
<

设置较宽作用域目录会清除较窄的作用域：
	- global(|:cd|) 	清除 tab、 window 本地目录
	- tab (|:tcd|) 		清除 window 本地目录
	- window(|:lcd|)	更改 window 本地目录
	- buffer(|:bcd|)	更改 buffer 本地目录

注意：buffer 本地目录永远不会被清除，除非通过 |:bcd| 或 |:bcd!|

- 可以使用 |getcwd()| 获取最终有效目录
- 可以通过 `:verbose pwd` 查看最终有效目录来自哪个作用域

==============================================================================
切换本地目录命令

:chd[ir]
:cd			将当前目录更改为主目录("~")，
			并取消设置与 ":cd {path}" 相同的目录
			
			":cd" 等同 ":cd ~"

			如果 'cdhome' 被禁用，则仅打印名称。
			使用 |:pwd| 可无论 'cdhome' 如何都打印它。

:cd {path}		将当前目录更改为 {path}，
			相对于 'cdpath' 解析(如果 {path} 是相对路径)
			在 MS-Windows 上，这也会更改活动驱动器
			
			清除窗口本地和标签页本地目录（在当前窗口/标签页上），
			但不清除缓冲区本地目录

:cd -			更改为上一个当前目录（在上一条 ":cd {path}" 命令之前）


:tch[dir]
:tc[d] [path]		类似 |:cd|，但仅为当前标签页设置目录，清除当前窗口本地
			目录，但不清除缓冲区本地目录
			不会更改其他标签页的当前目录，
			也不会更改任何其他具有其自身本地目录的窗口或缓冲区

			"粘性"行为：新标签页继承当前标签页本地目录

:tc[d] - 		更改为上一个标签页本地目录（在上一条 ":tcd {path}" 命令之前）


:lch[dir]
:lc[d] [path]		类似于 |:cd|，但仅为当前窗口设置目录。
			不会更改其他标签页、窗口或缓冲区的当前目录

			每当进入该窗口时，指定的目录成为当前目录，
			除非其当前缓冲区具有缓冲区本地 (|:bcd|) 目录

			"粘性"行为：新窗口继承当前窗口本地目录。

:lc[d] -		更改为上一个窗口本地目录（在上一条 ":lcd {path}" 命令之前）


:bch[dir]
:bc[d] [path]		类似于 |:cd|，但仅为当前缓冲区设置目录。
			不会更改标签页、窗口或其他缓冲区的当前目录

			不具有"粘性"：与 :lcd 和 :tcd 不同，
			新窗口或缓冲区（|:edit|、|:enew|……）不会"继承"当前缓冲区本地目录。
			如果你想要"粘性"行为，请使用 |:tcd| 或 |:lcd|。

:bc[d] -		更改为上一个缓冲区本地目录（在上一条 ":bcd {path}" 命令之前）



:lc[d]!			取消设置窗口本地当前目录。
:tc[d]!			取消设置标签页本地当前目录。
:bc[d]!			取消设置缓冲区本地当前目录。


每一个仅取消设置其自身的作用域，因此下一个更高作用域生效。
如果该作用域没有本地目录，则不执行任何操作。

全局目录始终存在，因此 ":cd!" 等同于 |:cd|。

==============================================================================
当前目录名称


:pw[d]			打印当前目录名称
			当 'verbose' 非零时，|:pwd| 还会显示当前目录是在哪个作用域设置的。
			示例： >

				" 由 :cd 设置
				:verbose pwd
				[global] /path/to/current

				" 由 :tcd 设置
				:verbose pwd
				[tabpage] /path/to/current
<

getcwd([{winnr} [, {tabnr} [, {bufnr}]]])
		不带参数时，返回有效的 |current-directory|。
		使用 {winnr}（|window-number| 或 |window-ID|）、{tabnr} 或 {bufnr} 时，
		返回该作用域的工作目录，忽略 'autochdir'。

		- 如果 {winnr} 为 -1：获取标签页目录。
		- 如果 {winnr} 和 {tabnr} 均为 -1：获取全局目录。
		  - 注意：当 {tabnr} 为 -1 时，Vim 返回空字符串。
		- 如果给出了 {bufnr}：获取缓冲区本地目录。
		  （{winnr} 和 {tabnr} 必须为 -1。）
		- 仅当前面的参数均为 -1 时，参数才可为 -1。*E5001*

		标签页、窗口和缓冲区由它们各自的编号标识，0 表示当前标签页/窗口/缓冲区。
		缺少 {tabnr} 隐含为 0（缺少 {bufnr} 则不然；见下文）。因此以下写法等效： >vim
		    getcwd(0)
		    getcwd(0, 0)
<
		每种形式报告其自身作用域或“更宽”的作用域，因此例如 {winnr} 从不报告缓冲区本地目录。
		{bufnr} 形式会回退到全局目录，因为缓冲区不属于任何特定的窗口或标签页。

		示例： >vim
		      getcwd(-1, -1, 0)  " 获取当前缓冲区的目录
		      getcwd(-1, -1, 3)  " 获取缓冲区 3 的目录
		      getcwd(-1, -1, -1) " 获取全局目录
		      getcwd(-1, -1)     " 获取全局目录
<

                参数： ~
                  • {winnr}（`integer?`）
                  • {tabnr}（`integer?`）
                  • {bufnr}（`integer?`）

                返回值： ~
                  （`string`）
